## 🚀 **Installation & Usage**

### **Quick Install**
```bash
cd mcp-accurate-click-server
pip install -e ".[all]"
playwright install chromium
```

### **Run Demo**
```bash
python -m mcp_server --demo
```

### **Use as MCP Server**
```bash
python -m mcp_server --stdio
```

### **Configure Claude Desktop**
```json
{
  "mcpServers": {
    "accurate-click": {
      "command": "python",
      "args": ["-m", "mcp_server", "--stdio"]
    }
  }
}
```
