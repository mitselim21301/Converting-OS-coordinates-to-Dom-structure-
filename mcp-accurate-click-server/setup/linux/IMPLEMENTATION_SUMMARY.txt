DISPLAY SERVER COMPATIBILITY
================================================================================

X11 (Traditional):
  - Full feature support (100%)
  - All tools available
  - Optimal performance
  - Fallback chain: pynput → python-xlib → xdotool
  - Recommended for production

Wayland (Modern):
  - Partial support (80%)
  - Limited tool availability (wmctrl, xdotool are X11-only)
  - pynput provides fallback support
  - Improving as Wayland ecosystem matures
  - Use X11 session for best compatibility

Automatic Detection:
  - XDG_SESSION_TYPE environment variable
  - WAYLAND_DISPLAY or DISPLAY fallbacks
  - User-friendly notifications

================================================================================
TROUBLESHOOTING GUIDE
================================================================================

ISSUE 1: "Distribution not recognized"
  CAUSE: Unsupported or unusual distribution
  FIX: Check os-release: cat /etc/os-release
       Report issue with distribution ID

ISSUE 2: "xdotool not found"
  CAUSE: Package not installed
  FIX: Run setup script: sudo python3 setup.py
       Or manual install (see LINUX_COMPATIBILITY.md)

ISSUE 3: "Python module not found"
  CAUSE: Python package not installed
  FIX: pip3 install pynput python-xlib psutil

ISSUE 4: "Wayland not supported"
  CAUSE: Using Wayland, some tools are X11-only
  FIX: Select "GNOME on Xorg" at login screen
       Or use X11 session

ISSUE 5: "Permission denied"
  CAUSE: Trying to install without sudo
  FIX: Use sudo: sudo python3 setup.py
       Or manually install as root

ISSUE 6: "SELinux blocking tools" (Fedora/RHEL)
  CAUSE: SELinux policy preventing tool execution
  FIX: Temporary: sudo setenforce 0
       Permanent: Update SELinux policies
