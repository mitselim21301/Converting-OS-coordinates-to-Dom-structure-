## 🚀 Quick Start Commands

```bash
# Install dependencies
pip install -r requirements_vision.txt

# Install system dependencies (Ubuntu)
sudo apt-get install tesseract-ocr

# Install Playwright browsers
playwright install

# Run minimal example
python -c "
from implementation_examples import HybridCoordinateValidator, BoundingBox, ScreenCapture
validator = HybridCoordinateValidator()
bbox = BoundingBox(x=100, y=100, width=200, height=100)
screenshot = ScreenCapture.capture_region(bbox)
print('Vision validation system ready!')
"
```

## 📝 Cheat Sheets

### Validation Method Selection

**Need speed (< 50ms)?**
→ Template matching only
→ See: VISION_RESEARCH.md §5.A

**Need accuracy (> 90%)?**
→ AI validation (GPT-4V or Claude)
→ See: AI_VISION_APPROACHES.md §1

**Need balance?**
→ Template + OCR + Edge detection
→ See: HYBRID_VALIDATION_ARCHITECTURE.md §2.2

**Need text verification?**
→ OCR (Tesseract or EasyOCR)
→ See: VISION_RESEARCH.md §3

**Need zero-shot?**
→ CLIP or OWL-ViT
→ See: AI_VISION_APPROACHES.md §5
